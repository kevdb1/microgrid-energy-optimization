# Microgrid Energy Optimization

## Overview

This project develops a two-node microgrid optimization model using
Python, PyPSA, and HiGHS. The model evaluates renewable generation,
battery storage, transmission congestion, locational marginal prices,
and carbon-pricing scenarios.

## Key Features

- Renewable generation and electricity demand modeling
- Battery charge and discharge optimization
- Transmission capacity constraints
- Locational marginal price analysis
- Carbon-price sensitivity analysis
- Scenario comparison and visualization

## Tools

- Python
- PyPSA
- HiGHS
- pandas
- matplotlib

## Key Results

- Battery storage shifted energy from low-cost to high-cost hours.
- Transmission congestion produced price differences between nodes.
- Carbon pricing changed dispatch, emissions, and total system cost.

## Files

- `microgrid_optimization.ipynb`: complete model and analysis
- `microgrid_optimization_report.pdf`: full project report
- `figures/`: selected result figures
